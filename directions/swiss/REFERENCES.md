# Swiss: references

## Concept

The home page is a typographic programme in Gerstner's sense: a set of rules (a modular grid, a baseline, one type family on two axes, and "every element keeps its column count") rather than a fixed layout. The only picture is type: the name, a statement, and columns of small running prose (8–9px; the essays' placeholder Latin until real excerpts exist). At load, a new column enters: the grid re-divides from 12 to 13, and every element keeps its column count, so everything re-proportions. The name keeps its size and gives up width on the width axis, and the text columns narrow and re-flow word by word. Then the composition reorganises around the new column rather than just making room for it. The name re-breaks into a justified two-line block. The column splits into short inline pieces that enter the text stream, and everything downstream re-flows. Last, the camera pulls back: the page is one sheet among many, and each sheet runs the same programme when the change reaches it, nearest first. The site's one recognisable move is absorption: on scroll the text clears, the column's pieces cross the empty grid into the text, and the text is set again around them. In the hero a visitor can take a piece from the column by clicking between two words; inner-page titles absorb a module the same way. No illustration, no labels, and one signal colour, used only as a fill.

## Primary sources (lineage)

- **Josef Müller-Brockmann, *Grid Systems in Graphic Design* (1981).** The modular grid as the page's constitution, with text greeked as lines of tone and headlines as black bars. Only the distant sheets in the pull-back use that convention.
- **Müller-Brockmann, Tonhalle / *musica viva* posters.** MoMA: https://www.moma.org/collection/works/7233 (1958), https://www.moma.org/collection/works/4885 (1957). Type only; the composition carries the structure instead of depicting it. Taken: the flush-left, asymmetric placement of a very large name against small, exact text blocks.
- **Wim Crouwel, *Vormgevers*, Stedelijk Museum, 1968.** MoMA: https://www.moma.org/collection/works/8735 · Stedelijk: https://www.stedelijk.nl/en/collection/14788-wim-crouwel-vormgevers. The grid is shown, not hidden, and every letter is placed by it. Taken: visible hairline columns that themselves move when the grid re-divides.
- **Emil Ruder, *Typographie* (1967).** One family; contrast comes from size, weight and width rather than from many faces. Taken: a single variable family (Archivo, wdth 62–125, wght 100–900) does every job on the site.
- **Karl Gerstner, *Designing Programmes* (1964).** Design as a rule system that produces many solutions. Taken: each sheet in the field has its own composition, but all of them run the same rule when the change arrives.

## Awwwards

- **Exat Typeface, Site of the Day, 3 Apr 2025** (https://www.awwwards.com/sites/exat-typeface → https://exat.hottype.co/). A kinetic type site in two colours, where scroll and pointer drive the letterforms themselves. Taken: type as the only actor, and the discipline of two colours plus one accent.
- **Mat Voyce, Site of the Day, 30 Jan 2025** (https://www.awwwards.com/sites/mat-voyce). A type designer's portfolio with a proportional scaling system. Taken: text ratios recomputed from the viewport rather than set by breakpoints, which is how the stage fits the name to its measure at any width.

## Palette, type, logo

- Offset grey `#ecece8` (sheet), ground `#d9d9d4` (between sheets), ink `#0e0e0d`, and carmine `#d0263a` (the proofreader's insertion-mark red), which is only ever a fill (the new column, the inline pieces, the reading bar), never text.
- Archivo variable (width and weight axes, SIL OFL), self-hosted, one family only.
- Logo: the name with one carmine module set between its two words ("Corollary ▮ Labs"). The favicon is four columns with the third one carmine.
